# Проект в рамках образовательного курса Aston
Приложение на Java, которое реализовывает ввод, вывод и сортировку данных.
Требования:
- maven 3.11.0;
## Подготовка
Скачиваем с репозитория:
 ```
    git clone git@github.com:arsagyr/JavaLearningProject.git
 ```
## Установка
Скачиваем с репозитория:
 ```
    git clone git@github.com:arsagyr/JavaLearningProject.git
 ```
## Запуск
Переходим в папку с проектом и запускаем make:
```
    make run
```
