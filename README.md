# Проект в рамках образовательного курса Aston
Приложение, которое реализовывает ввод, вывод и сортировку данных.
## Как пользоваться?
Программа должна выполняться в цикле. Выход из цикла возможен только путем соответствующего выбора пользователя. Пользователь должен иметь возможность выбирать варианты заполнения исходного массива данных (из файла, рандом, вручную) и его длину.
В программе должен использовать паттерн стратегия. 
Сортировать необходимо кастомные классы - класс должен иметь реализованный паттерн Builder. Для вводимых данных (в тч из файла) должна производиться валидация данных.
Сортировка должна быть базово реализована по всем 3 полям.
